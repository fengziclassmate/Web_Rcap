# 个人科研与生活执行工作台

仅面向桌面浏览器的个人工作台，用于管理周日程、长期与日常任务、年度计划、项目打卡、购物清单、花销和生活/科研日志。

## 本地运行

1. 运行 `npm install`。
2. 将 `.env.example` 复制为 `.env.local`，填入现有 Supabase 项目的配置：
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`：客户端 publishable key，或现有的 anon public key。
   - 可选：`LLM_ALLOWED_BASE_URLS`，逗号分隔的可信 HTTPS AI 网关根地址。未配置时只允许各服务商默认地址；不要填入不可信或内网目标。
   - 使用 AI 配置时必须设置 `LLM_CONFIG_ENCRYPTION_KEY`：32 字节随机密钥的 64 位十六进制文本，仅放在服务端环境变量中。多实例部署须使用同一密钥，不得添加 `NEXT_PUBLIC_` 前缀。更换密钥后需要重新填写 AI 配置。
3. 运行 `npm run dev`，访问 [http://localhost:3000](http://localhost:3000)。

### 科研与自学

- 在个人日程右侧的任务控制台中打开「科研与自学」。控制台卡片显示项目进度和下一里程碑，点击项目或「管理项目与任务」展开完整任务表。支持空白、科研、自学三种起步模板，项目可以填写目标与验收标准、说明和目标日期。
- 任务包含名称、阶段、标签、四象限优先级、状态、计划日期、截止日期、里程碑、内容、备注与资料、成果与复盘。表格可直接调整优先级和状态；看板按状态分栏。
- 任务表采用紧凑标题与工具栏，筛选按需展开，详情仅显示已填写字段。底部输入任务名后按 Enter 直接新增；需要完整填写时使用「新任务」。
- 「今天要做」包含今天计划执行或已到截止日期的未完成任务；「本周计划」包含周一至周日内从今天起的计划／截止任务和逾期任务。归档项目单独收纳。
- 点击任务名称编辑内容。选中文字可用工具栏加粗、高亮、下划线、删除线或设置红／蓝／绿色；也可以输入符号：`**加粗**`、`==高亮==`、`~~完成标注~~`、`__下划线__`、`{red}红字{/red}`、`{blue}蓝字{/blue}`、`{green}绿字{/green}`。支持组合标注、简单标题与 `[资料名](https://example.com)` 链接，不执行用户输入的 HTML。
- 使用 `- [ ] 子任务` 和 `- [x] 已完成子任务`；工具栏可将选中行转换为子任务。预览和展开的表格行均可直接勾选。任务完成状态独立于子任务，完成日期自动记录；项目进度按已完成任务数计算。
- 支持内容搜索、阶段／优先级／状态筛选、排序、全局搜索定位、当前结果 CSV 导出、全部项目 JSON 备份与追加导入、项目归档／恢复，以及工作台撤销／重做。JSON 导入会生成新 ID，保留现有记录。
- 「复制到今日待办」生成一条独立的日常任务，相同项目任务不会重复复制；两处记录分别编辑和完成。
- 数据复用现有账号隔离、离线草稿、版本检查和冲突选择。上线前执行 `supabase/migrations/20261016082720_add_project_boards.sql`。未迁移时，项目修改保留在本机并提示待迁移，现有日程仍可同步。迁移完成后点击顶部重试。跨电脑同步需要两台电脑都使用当前版本。

本机 Windows 若遇到测试工具无法写入系统临时目录，可将当前进程的 `TEMP` / `TMP` 指向项目内临时目录后运行测试。临时工具与浏览器验证文件存放于已忽略的 `.local-tools/`、`.qa/`。


### 执行工作台

- 右侧任务控制台包含日常任务、今日科研进展、跟进事项、科研与自学、任务与清单、项目与生活记录、时间与专注。点击「调整顺序」后拖动手柄排序，也可通过上移／下移按钮或手柄上的方向键调整；点击「完成排序」恢复内容展示。折叠和输入内容在排序时保持不变，布局随账号保存并同步。现有「任务与清单」和「项目与生活记录」各作为一组移动，组内仍通过原有按钮切换。
- 悬浮窗口：始终保持在页面可见区域，拖动顶部移动，方向键微调、Home 恢复位置。可切换「接下来 / 今日日程 / 今日待办」，收起为摘要或隐藏后从右下角恢复。日程可打开编辑，待办可直接完成；位置和展示选择按账号保存在本机浏览器，不跨设备同步。
- 事件缓冲功能已取消。旧缓冲字段不再展示或扣减空闲时间，事件原有起止时间保持不变。
- 快捷键：顶部「快捷键」按钮或 Ctrl/Cmd+/ 打开设置，可搜索并自定义 17 项操作，支持冲突提示、单项停用和恢复默认。设置按账号保存在当前浏览器，编辑文字或打开弹窗时暂停工作台快捷键。
- 全局搜索：默认 Ctrl/Cmd+K，覆盖任务、日程、日志、年度目标、项目与购物清单；任务、日程和日志可打开原有编辑器。
- 撤销/重做：顶部按钮或默认快捷键 Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z，保留本次打开页面最近 30 次任务、日程、清单、打卡与成就变更。同批关联修改整体恢复，输入框保留原生文本撤销。日志、花销与专注记录不在此撤销范围内。
- 容量提示：自定义一天可安排的时间范围；从当前时刻扣除合并后的占用区间，待办使用现有任务估时上限，扣除已安排的剩余时段。未估时任务单独提示。
- 专注计时：支持 25 分钟、50 分钟目标及自由计时，可选择今日待办、日程、科研与自学项目任务。日常任务和项目任务行可一键开始 25 分钟专注，并自动展开专注模块；已有专注时打开当前计时，不覆盖已有记录。到达目标后保留超时，结束时保存实际投入。
- 专注记录：计时状态和历史按账号同步到 Supabase，换电脑登录后恢复同一轮目标、已投入时长及暂停状态。原有本机记录首次打开时合并上传；离线修改保留草稿，联网后重试。暂停／继续片段合并为一轮，跨设备重叠片段不重复累计；刷新和关闭页面不自动停止计时。
- 复盘统计：查看每周每日计划/实际、分类分布、按完成日期统计的任务数量及本周到期未完成任务。实际仅来自已保存的专注片段，不以勾选完成推算耗时。
- 专注同步需执行 `supabase/migrations/20261016102614_sync_focus_state.sql`；沿用 `schedule_data` 的账号隔离、版本检查和冲突选择。页面重新聚焦时拉取更新，前台计时中每 10 秒检查云端版本，空闲时每 30 秒检查，不按秒写入数据库。
- 重复行程编辑支持开始／结束日期。「仅此日」改日期时拆出单次行程；「当天及未来」移动后续系列，周几规则、例外与备注覆盖随日期一起平移，过去的日程保持原样。

### 保存与恢复

- 日程及任务使用按账号隔离的本机草稿；顶部显示待同步、已同步、离线和错误状态。恢复网络或重新聚焦窗口后自动重试。
- 多页写入依据 `updated_at` 检查版本，并合并不冲突的修改；同一内容发生冲突时需要用户选择。外部数据回填会重置当前撤销历史，避免撤销其他页面的记录。
- 桌面浏览器优先通过 Web Locks 协调本机草稿接管；不支持时使用 IndexedDB 串行事务。两者都不可用时显示错误并禁止进入可编辑工作台，避免未保存修改。
- 聊天、速记、周报、分类和模板按账号保存。旧版未标明账号的本机记录仍保留，但不会自动归属到某个账号。
- 日志与花销仍需要联网；日志提交失败保留输入和同一提交 ID，重复提交不会重复创建正文或同一张草稿图片。保存期间冻结表单，完整保存后才清空。
- 日志删除先使用数据库级联删除，再清理图片对象；清理失败按账号记录并重试。上传结果不确定的图片不会被后台自动删除，避免与重试发生竞态；放弃上传后可能留下待服务端回收的孤立对象。
- AI 配置使用服务端密钥进行 AES-256-GCM 加密，绑定当前账号并校验过期时间。旧明文 cookie 不再接受，需要重新输入一次。加密 cookie 仍保存在浏览器，不是服务端凭据库。
- 图片上传、邮箱认证和数据库 RLS 需要在真实测试账号下验收。

本轮审查与验收记录见 [2026-10-02 系统审查](./docs/quality-review-2026-10-02.md)。当前框架版本以 `package.json` 为准（Next.js 16.3.8）。
