# 子任务表与项目排序复核

## 数据与兼容

- 为项目任务增加结构化子任务数组，包含 ID、名称、备注和状态，沿用现有 project_boards JSON 数据同步，不增加数据库列。
- 仅对未含子任务数组的旧任务提取 Markdown 清单；稳定 ID 根据任务 ID 与原行号生成，保留重复条目及完成状态，移除的标注保留文字和资料 URL，其余正文、任务备注不变。
- 已有数组保持原样规范化，删除全部子任务后不会因再次加载而重新生成。备份、导入、CSV、全局搜索和复制到今日包含子任务内容。
- 项目排序保持非当前分组的归档位置，基于最新数组更新，不以旧快照覆盖内容。

## 交互与布局

- 任务备注常显，子任务逐行展示，名称和备注可直接编辑；状态改为不带箭头的标签。
- 子任务表在外层展开区与详情编辑器共享，添加行不会误提交父表单，删除需确认。
- 项目支持真实鼠标拖动、键盘方向键、状态播报与键盘焦点恢复；排序不会切换已选项目。
- 1600px 与 1180px 窗口检查长文本，页面无横向溢出，较窄窗口的表格内部滚动。

## 验证

- 41 个测试文件、290 项测试通过，覆盖旧数据转换、重复项、幂等、JSON 回读、子任务备注／状态并发合并、项目排序与远端备注合并、CSV、子任务搜索、父表单防误提交及草稿冲突恢复。
- ESLint 与干净的 Next.js 生产构建通过。
- 本机隔离账号实际保存任务备注、子任务备注和状态，调整项目顺序后刷新，内容及顺序均恢复；真实鼠标拖动和键盘排序均已验证。
- 任务表工作区的 WCAG 2 A/AA 检查未报告违规；选中导航文字有一项自动判定不完整，人工复核深绿文字与浅绿背景。生产包详情窗口没有横向溢出，浏览器页面错误为空。
- 详情窗口同样采用无箭头状态标签，并缩短空内容编辑区；发布前再运行 25 项相关测试，全部通过。
