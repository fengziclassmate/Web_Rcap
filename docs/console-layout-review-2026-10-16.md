# 控制台与花销布局复核

本轮重新安排字段和操作的关系，保留正文和数字需要的空间。

- 今日科研进展：日期、七日状态、三行记录、底部操作分层；三个文本区始终可见，长内容可增长和调整高度，草稿、补记、休息日及保存流程保留。
- 日常任务：排序和收尾入口改为图标；重点任务使用星标，取消重复列表；名称换行，日期与专注操作独立对齐，压缩完成记录和临期区域。

- 花销输入框统一 32px，标签间距统一；修正原先分类框比金额框低 2px 的问题。支出金额右侧对齐，长备注不挤动操作。三个预算输入与按钮共用基线。

- 行程详情恢复为 600px，重排时分为连接控件，验证每个时间数字完整显示。底部固定工具保留空间。

验证使用隔离的演示账号、长任务、科研草稿、多条花销、长备注及预算数据。检查不同桌面宽度下的溢出与对齐；通过模块排序验证输入不丢失。控制台及花销的局部 axe WCAG 2A/2AA 检查均为 0 个违规、0 个待人工确认项。

41 个测试文件、281 项测试通过，ESLint 与生产构建（含 TypeScript）通过。检查了 1180、1600、1920px 宽度：无横向溢出；五个录入控件的顶部位置和高度完全一致，预算输入与保存按钮共用基线，三笔支出的金额右边界一致。生产 CSS 包含新版科研行、日常录入与七日花销布局。
