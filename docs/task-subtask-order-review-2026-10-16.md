# 任务与子任务排序复核

## 实现

- 共用拖动与键盘排序逻辑，支持落点反馈、分组边界、焦点恢复与屏幕阅读器播报。
- 任务表、看板及详情子任务表均可排序；任务默认使用手动顺序，从其他排序视图拖动后以当前可见顺序为基础保存并切回手动顺序。
- 仅重排所属项目／父任务中的条目，使用最新记录对象，筛选隐藏的条目保持位置；不会恢复已删除条目，不改变备注、状态或所属项目。
- 任务数组与子任务数组沿用已有 project_boards 同步、备份及三方合并，无新增数据库字段或迁移。

## 验证

- 41 个测试文件、298 项测试通过；Lint 和干净生产构建通过。
- 覆盖任务及子任务拖动、键盘排序、筛选与隐藏条目、自动排序转手动排序、看板状态边界、详情保存、展开区拖放与草稿保留。
- 验证排序与远端任务／子任务备注和状态合并，JSON 备份回读保留顺序，删除条目不因排序而恢复。
- 使用两个独立浏览器连接本机模拟云端，验证另一浏览器可读到任务和子任务的新顺序；刷新仍按手动顺序展示。实际鼠标拖动任务行、子任务行和看板卡片，以及任务键盘排序均已通过。
- 1180px 窗口检查页面无横向溢出，浏览器页面错误为空。
- 最终生产包再次实际拖动任务与子任务，首项按预期变化；工作区 WCAG 2 A/AA 检查未报告违规。选中导航文字仍有一项自动判定不完整，已人工复核既有深绿文字与浅绿背景。
- 回归时发现浮窗测试在移除 ResizeObserver 模拟对象前未卸载组件，显式先 cleanup，修正偶发的测试清理时序问题。
