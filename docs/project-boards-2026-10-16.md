# 科研与自学任务表验收记录

日期：2026-10-16

## 交付范围

- 在个人日程的任务控制台内增加「科研与自学」摘要模块，打开宽弹窗管理完整任务表。
- 控制台模块支持拖动手柄排序、上下按钮、键盘方向键和恢复默认顺序；排序保留折叠状态、未提交输入和专注计时状态。现有两个标签切换组按组移动，模块顺序保存在账号的 `ui_preferences.dashboardSectionOrder`，本轮布局调整无需新增数据库迁移。
- 独立项目任务表，包含科研／自学起步模板、目标与验收标准、项目说明和目标日期。
- 任务支持四象限优先级、状态、阶段、标签、里程碑、计划与截止日期、子任务、资料和成果复盘。
- 提供表格与状态看板、今天／本周／逾期视图、搜索筛选、CSV 导出、JSON 备份与追加导入、归档和恢复。
- 标注工具将选区转换为安全的文本符号，支持加粗、高亮、删除线、下划线、三种文字颜色、简单标题与 HTTP(S) 资料链接。用户 HTML 按文本显示。
- 全局搜索可定位项目与项目任务。项目变更进入现有撤销历史；复制到今日待办生成独立记录，不声称两处完成状态联动。

## 数据与审查结论

项目数据使用新的 `schedule_data.project_boards` 字段，避免覆盖以前移除的科研模块数据。复用原有账号隔离、本机草稿、乐观版本检查和冲突选择。JSON 导入追加新 ID，不覆盖原项目；CSV 对可能被表格软件当作公式的内容增加文本前缀。

数据库尚未迁移时，读取回退到旧字段，日程继续同步；项目修改保持待同步草稿并显示迁移提示。迁移后重试即可同步。编辑窗口只提交用户改动的字段，避免覆盖其他页面更新的独立字段；同一字段发生变化或任务已被删除时拒绝覆盖，并保留输入供复制核对。关闭或刷新包含未保存修改的编辑器会提示。
