# ADR-0001：仅维护桌面 Web 平台

- 状态：已接受
- 日期：2026-07-15

## 背景

项目曾通过 Capacitor 和 Android 工程提供移动端构建，并在工作台中维护手机专用底部导航、页面切换状态和安全区样式。当前产品不再考虑移动端，继续维护双平台会扩大依赖、构建和布局验证范围。

## 决策

应用只发布和维护桌面 Web 版本：

- 删除 Capacitor、Android 工程和移动构建脚本；
- 删除手机专用导航、状态与安全区布局；
- 工作台设置桌面最小宽度，并始终展示日程与任务双栏；
- 保留对桌面窗口尺寸变化有价值的弹性布局，不承诺手机视口体验。

## 结果

后续功能只需验证浏览器桌面环境。任何重新引入移动平台的提议都必须重新评估数据同步、离线能力、发布链和独立交互设计，不能恢复旧的条件分支作为临时兼容。
