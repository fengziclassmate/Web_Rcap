# ADR-0001：以桌面 Web 为主，提供 Windows 桌面显示入口

- 状态：已接受
- 日期：2026-07-15
- 修订：2026-10-29，按用户要求增加可选 Windows 半透明桌面显示容器。

## 背景

项目曾通过 Capacitor 和 Android 工程提供移动端构建，并在工作台中维护手机专用底部导航、页面切换状态和安全区样式。当前产品不再考虑移动端，继续维护双平台会扩大依赖、构建和布局验证范围。

## 决策

应用以桌面 Web 为主要版本：

- 删除 Capacitor、Android 工程和移动构建脚本；
- 删除手机专用导航、状态与安全区布局；
- 标准网页工作台设置桌面最小宽度，并默认展示日程与任务双栏；
- 保留对桌面窗口尺寸变化有价值的弹性布局，不承诺手机视口体验。
- Windows 桌面容器直接加载现有工作台，复用原账号和业务逻辑；不维护另一份日程数据。容器负责桌面层级、背景透明度、位置与窗口大小，网页负责内容布局和编辑。

## 结果

网页功能验证桌面浏览器；容器变更另行验证 Windows 桌面附着、DPI 坐标、输入、透明显示及便携版启动。任何重新引入移动平台的提议都必须重新评估数据同步、离线能力、发布链和独立交互设计，不能恢复旧的条件分支作为临时兼容。
