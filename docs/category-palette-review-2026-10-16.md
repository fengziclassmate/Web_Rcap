# 分类配色一致性复核

## 原因

线上“健身、球类运动、跑步、户外运动”沿用旧黄绿色，“运动”采用另一绿色。此前仅迁移颜色恰好等于原默认值的内置分类，历史自选颜色与不同 ID 的分类未覆盖；18% 底色也使相近色进一步接近白色。

## 修复

- 旧版常用分类统一迁移为色板版本 2，不再依赖原 ID 或原颜色是否等于默认值；保留分类身份、顺序、图标与未识别自建分类。
- 同类生活活动共享颜色，科研环节使用独立色相；日／周／月卡片共用更清晰的底色和边框。
- 版本标记与分类设置共同保存，迁移完成后的手动配色可继续保存，刷新不重置。
- 日历日期取消降低透明度，日志日期加深，修正审查发现的文字对比度问题。

## 验证

- 分类迁移、幂等、后续手动改色、旧 ID 与别名、未识别分类保留的测试通过。
- 新增日程卡片交互测试，使用旧黄绿／翠绿的运动设置验证实际显示一致，并检查持久化版本。
- 全量 41 个测试文件、285 项测试通过。使用本机隔离账号模拟混杂旧配色，验证全部五类运动颜色一致、刷新恢复，目视检查 18 个日程与六个科研环节。
- ESLint 与干净生产构建通过；使用新隔离浏览器会话复查日历区域 WCAG 2 A/AA，违规和待人工判定项均为 0，页面错误为空。
